# PM Hive Vancouver Web

This is the official repository for the PM Hive Vancouver community website.

## 🚀 Getting Started

To get started with this project, follow these steps:

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/seykafu/pm-hive-vancouver-web.git
    ```
2.  **Install dependencies**:
    ```bash
    npm install
    ```
3.  **Set up Supabase**:
    Follow the instructions in `AUTHENTICATION_SETUP.md` to set up your Supabase project and environment variables.

4.  **Run the development server**:
    ```bash
    npm run dev
    ```

## ✨ Features

-   **React + Vite**: A modern, fast, and efficient frontend stack.
-   **TypeScript**: For type-safe and scalable code.
-   **Tailwind CSS**: A utility-first CSS framework for rapid UI development.
-   **shadcn/ui**: Beautifully designed and accessible UI components.
-   **Supabase**: For authentication, user management, and database storage.
-   **React Router**: For client-side routing.
-   **Framer Motion**: For smooth and beautiful animations.
